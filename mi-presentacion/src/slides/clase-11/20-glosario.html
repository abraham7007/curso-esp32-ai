02 · Agentes de IA en el flujo embebido

Glosario de la sesión

Runtime embebido embedded runtime

Firmware que ejecuta comportamiento definido fuera del binario: guiones, reglas, configuración o modelos. El binario pasa a ser plataforma.

Máquina virtual de aplicación application virtual machine

Entorno que ejecuta módulos compilados a un formato portable, con aislamiento entre el módulo y el resto del sistema.

Aislamiento de fallos fault isolation

Propiedad por la que el fallo de un módulo no compromete al resto. Separa cargar código arbitrario de cargarlo con permisos declarados.

Determinismo determinism

Propiedad de un sistema cuyo peor caso puede acotarse. La recolección de memoria y el despacho dinámico de un intérprete la dificultan.

Cumplimiento aparente apparent compliance

Modo de fallo en que el código hace lo pedido pero incumple un requisito temporal. Supera la compilación y las pruebas funcionales.

Superficie de ataque attack surface

Todo aquello por lo que se puede influir en el dispositivo. Con comportamiento externo incluye el canal por el que se envía el guion.

MCP model context protocol

Protocolo por el que un agente consume herramientas y datos. El dispositivo puede actuar en los dos papeles: cliente y servidor.

Contexto context

Información que se entrega a un asistente: hoja de datos, configuración del proyecto, interfaces y restricciones. Su calidad determina la del resultado.

Margen de actuación action bounds

Intervalo dentro del cual se acota lo que un agente propone. Va compilado en el firmware, no en la configuración que el agente puede cambiar.

Versionado del comportamiento behaviour versioning

Registro de qué guion o regla lleva cargada cada unidad. Sin él, dos equipos iguales se comportan distinto sin que conste por qué.
