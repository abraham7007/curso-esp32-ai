La hora del código Ejemplo 14

Serialización de tres medidas en una línea JSON

Proyecto Documento JSON con ArduinoJson. platformio.ini · src/main.cpp
Simulación Una placa, salida por USB. diagram.json · wokwi.toml
Diagrama Flujo y comparativa de tamaño. diagrama-flujo-json.excalidraw · diagrama-comparativa-json.excalidraw

Qué debe hacer

Cada 3 s, componer un documento JSON con temperatura, humedad, presión y tiempo desde el arranque, y escribirlo en una línea del monitor.

Montaje

Una sola placa y ninguna conexión: las medidas son valores al azar y la línea sale por el USB (UART0).

ESP32-WROOM-32

Prompt para el asistente

1. Proyecto. Crea un proyecto nuevo de PlatformIO para esp32dev con Arduino y monitor_speed = 115200; declara en lib_deps bblanchon/ArduinoJson @ ^6.21.5. 2. Firmware. setup() imprime «\n--- GENERADOR DE JSON INICIADO ---». Cada 3 s, en un StaticJsonDocument<200>: temp = 20.0 + random(0, 100) / 10.0 y presion = 1010.0 + random(0, 50) / 10.0 como float, hum = random(40, 80) como int y tiempo_ms = millis(). Imprime «Generando JSON: » y, en la misma línea, serializeJson(doc, Serial). El texto no se arma a mano con sprintf. 3. Simulación. Añade la simulación de Wokwi con un ESP32 solo. 4. Diagramas. En Excalidraw: el flujo crear documento → asignar → serializar, y una comparativa del mismo registro en JSON y en binario con los bytes contados.

Por qué se pide así. Fijar la versión 6 evita la API de ArduinoJson 7, donde StaticJsonDocument queda obsoleto. Sin sprintf, comillas, comas y llaves las pone la biblioteca.

Salida esperada

Qué comprueba. Cada valor viaja con su nombre y el receptor no necesita conocer el programa emisor; a cambio, la línea ocupa unos 68 bytes para cuatro números.

Pregunta de predicción: ¿por qué el monitor muestra 23.70000076 y no 23.7? Respuesta: el float más próximo a 23,7 vale 23,7000007629…; ArduinoJson 6 en el ESP32 guarda los números como double (ARDUINOJSON_USE_DOUBLE = 1) y los escribe con nueve cifras significativas, sin ceros finales: 25,0 sale como 25 y 1010,5 como 1010.5. Declarado como double, 23,7 saldría como 23.7. Los números y los instantes de la traza son ilustrativos: random() cambia en cada ejecución.

Para estudiar

En la práctica

serializeJson() escribe directamente en el puerto, sin cadena intermedia; measureJson() devuelve los bytes que ocupará. Un documento estático de 200 bytes reserva ese espacio en la pila para el árbol del documento.

Errores frecuentes

  • Capacidad insuficiente: las claves sobrantes se pierden sin aviso; overflowed() lo detecta.
  • Instalar ArduinoJson 7 sin fijar versión: avisos de obsolescencia.
  • Comparar el JSON con el binario sin contar las claves.
