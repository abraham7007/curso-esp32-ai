Endianness y alineación de estructuras

Definición

El endianness (orden de bytes) es la disposición en memoria de los bytes de un entero: little-endian coloca primero el menos significativo, big-endian el más significativo. La alineación es el relleno que el compilador inserta entre campos de una estructura para que cada uno empiece en una dirección múltiplo de su tamaño.

En la práctica

Se serializa campo por campo en un orden acordado, o se emplea un formato explícito como JSON, en lugar de volcar el contenido de la memoria con memcpy sobre el búfer de transmisión.

disposición en memoria · ESP32 
uint32_t v = 1000;   // 0x000003E8 en memoria: E8 03 00 00
                     // little-endian: primero el byte menos significativo

struct Medida {
    uint8_t  id;     // 1 byte  -> desplazamiento 0
                     // 3 bytes de relleno insertados aquí
    uint32_t valor;  // 4 bytes -> desplazamiento 4
};                   // sizeof(Medida) = 8, no 5
Los tres bytes de relleno no contienen ningún dato: existen para que valor empiece en una dirección múltiplo de 4.

Transmitir la estructura tal como está en memoria no es portable. Entre dispositivos con compiladores o arquitecturas distintas, el relleno y el endianness no coinciden: el receptor lee los campos desplazados y obtiene valores sin relación con los transmitidos, aunque no se haya perdido ni un solo byte.
