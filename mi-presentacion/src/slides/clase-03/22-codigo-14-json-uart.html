La hora del código Ejemplo 14

Serialización de un conjunto de medidas en formato JSON

Sobre el proyecto. El emisor compone un documento JSON con tres magnitudes y un timestamp, y lo manda por el enlace; el receptor lo interpreta y saca cada campo. La prueba se repite con memoria reservada de menos, para ver qué ocurre.

Conceptos clave

Serializar es convertir estructuras del programa en una secuencia de bytes que el otro extremo pueda reconstruir. Con un formato estándar, el acuerdo entre extremos lo sostiene una biblioteca en vez de un documento. El precio es la memoria reservada: el analizador necesita espacio proporcional al documento, y si falta, la deserialización falla. Por eso hay que comprobar su código de retorno y no dar el resultado por bueno.

Prompt para el asistente

Análisis

El primer par de líneas va y vuelve completo. En el segundo, la traza del emisor se corta a media cadena y el receptor devuelve IncompleteInput: el error no aparece al enviar sino al interpretar, y solo se ve porque se está comprobando el retorno. Si el programa no lo comprobara, seguiría con campos a cero sin ningún aviso.
