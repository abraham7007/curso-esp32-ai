Clase y objetos en C++

Cada objeto guarda sus datos. El código de toggle() es único y opera sobre el objeto invocado (this).

led.isOn() = true alarma.isOn() = false

Antes de pulsar. Pregunta de predicción: si se llama a led.toggle(), ¿cambia algo en alarma? Respuesta: no. Pulsar varias veces uno de los botones; el _state del otro objeto se mantiene. La flecha roja indica a qué objeto apunta this en esa llamada. Cada objeto ocupa 2 bytes de SRAM (_pin y _state); el código de los métodos está una vez en la Flash. alarma es un segundo objeto ilustrativo; el ejemplo 06 crea únicamente led.

Para estudiar

En la práctica

Led led(2); llama al constructor Led::Led(uint8_t pin) : _pin(pin), _state(false). Dentro de un método, _state significa this->_state: el del objeto con el que se llamó. sizeof(Led) vale 2.

Dónde aparece

Ejemplo 08: tres objetos LedIntermitente con periodos de 500, 800 y 1300 ms, cada uno con su propio instante de referencia.

Errores frecuentes

Guardar el estado en una variable static o global dentro de Led.cpp, que todos los objetos compartirían.
