03 · Tiempo sin bloqueo

Tipos para guardar el tiempo y desborde de millis()

32bits unsigned long en el ESP32: de 0 a 4 294 967 295
49,7días 232 ms hasta que millis() vuelve a 0

Constante del mismo tipo que millis():
static const unsigned long DEBOUNCE_DELAY = 30;

now − previo = 200 ms

Pregunta de predicción: con previo guardado 296 ms antes del desborde, 200 ms transcurridos y un período de 500 ms, ¿se cumple if (now >= previo + 500)?

Respuesta: sí, 300 ms antes de tiempo, porque previo + 500 desbordó y vale 204. La resta sin signo es aritmética módulo 232 y da 200, el tiempo real. Mover el deslizador más allá del desborde (296 ms): now pasa a valer casi cero y now - previo sigue dando el intervalo exacto. Con la resta, update() da el mismo resultado el día 50 que el día 1; la forma con suma falla una vez cada 49,7 días, un fallo difícil de reproducir al depurar.

Para estudiar

En la práctica

millis() devuelve unsigned long, de 32 bits en el ESP32 (equivale a uint32_t). Guardar el instante previo y los intervalos con ese mismo tipo, y comparar siempre now - previo >= intervalo.

Dónde aparece

Todo equipo que funciona semanas sin reiniciarse: estaciones de medida, controladores de riego, pasarelas.

Errores frecuentes

  • Guardar millis() en int: con signo, pasa a negativo a los 24,9 días.
  • Comparar contra una suma: now >= previo + intervalo.
  • Un #define sin tipo para la ventana, cuyo tipo depende de cada expresión.
