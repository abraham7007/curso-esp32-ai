05 · Temporización no bloqueante

Patrón begin() y update()

Definición

begin() configura el periférico una vez, y se invoca desde setup(): modo del pin, frecuencia, estado inicial. update() hace avanzar el módulo un paso y se invoca en cada iteración de loop(): lee, decide y devuelve el control sin bloquear.

En la práctica

Este par es la base de las Sesiones 4, 5 y 6 (driver de sensor, máquina de estados, cliente de red). Un módulo que respeta el patrón puede coexistir con otros en el mismo bucle; uno que espera dentro de sí mismo con delay() detiene a todos los demás durante esa espera.

src/main.cpp 
Led   led(2);      // el constructor solo guarda el pin
Boton boton(4);

void setup() {
  led.begin();     // configuracion, una sola vez
  boton.begin();
}

void loop() {
  boton.update();  // un paso por iteracion
  led.update();

  if (boton.fuePulsado()) led.toggle();
}
Ninguna clase conoce a la otra: main.cpp es el único punto donde se decide que una pulsación conmuta ese LED.
