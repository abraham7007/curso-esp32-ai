Estado del programa en una variable bool

bool automatico = false; setup() imprime [MODO] MANUAL

Manual

automatico == false
  • no llama a escribirPWM() y el LED conserva su último brillo
  • no imprime nada

boton.fuePulsado() imprime [MODO] AUTOMATICO

automatico = !automatico;

boton.fuePulsado() imprime [MODO] MANUAL

Automático

automatico == true
  • duty = voltios / 3,3 × 255
  • led.escribirPWM(duty)
  • imprime [AUTO] cuando el duty cambia

El programa del ejemplo 10 tiene dos comportamientos, que dependen del valor de automatico. La línea automatico = !automatico; hace las dos transiciones. Pulsar el botón de la lámina para recorrerlas. Pregunta de predicción: ¿qué hace el LED al volver a MANUAL? Respuesta: mantiene el último ciclo de trabajo, porque loop() deja de escribirlo. Con tres o más modos se usa un enum en lugar de un bool.

Para estudiar

En la práctica

if (boton.fuePulsado()) automatico = !automatico; y luego if (automatico) { … }. fuePulsado() devuelve true una sola vez por pulsación, así que cada pulsación cambia el modo exactamente una vez.

Dónde aparece

src/main.cpp del ejemplo 10. dutyPrevio es estado auxiliar que evita repetir la línea [AUTO]. (uint8_t)(v / 3.3 * 255) trunca: 1,65 V da 127.

Errores frecuentes

Leer el pin crudo con digitalRead() en vez de fuePulsado(): mientras se mantiene pulsado, el modo cambia en cada vuelta.
