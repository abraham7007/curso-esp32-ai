Modelo de tres capas

Definición

Acceso al hardware: lee y escribe periféricos, no decide nada. Lógica de aplicación: decide qué hacer con los datos, no toca hardware. Presentación o comunicación: muestra o transmite el resultado. Cada línea de código pertenece a una sola de las tres.

Fragmentos

Acceso al hardware lee y escribe periféricos
Lógica de aplicación decide con los datos
Presentación o comunicación muestra o transmite
