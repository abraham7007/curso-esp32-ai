06 · Composición y memoria de los objetos

Composición: objetos que contienen objetos

Definición

Composición (composition): una clase de nivel superior contiene instancias de otras clases como miembros y coordina su interacción, en lugar de reimplementar su comportamiento. El contenedor aporta la lógica que las relaciona; cada miembro conserva su propia responsabilidad.

lib/Regulador/Regulador.h · Regulador.cpp 
class Regulador {
public:
  Regulador();
  void begin();
  void update();
private:
  Boton _boton;               // instancia contenida
  EntradaAnalogica _entrada;  // instancia contenida
  SalidaPwm _salida;          // instancia contenida
  bool _automatico = false;
};

void Regulador::update() {
  _boton.update();  _entrada.update();   // cada miembro avanza su estado
  if (_boton.huboFlanco()) _automatico = !_automatico;
  _salida.escribir(_automatico ? _entrada.leerNivel() : 0);
}
Contención

Regulador

coordina · no reimplementa

Boton

GPIO 4 · detecta el flanco

EntradaAnalogica

GPIO 32 · promedia la muestra

SalidaPwm

GPIO 2 · fija el ciclo de trabajo

En la práctica

Los miembros se construyen en la lista de inicialización del constructor, no dentro del cuerpo: Regulador() : _boton(4), _entrada(32), _salida(2) {}. El begin() del contenedor llama al begin() de cada miembro, de modo que setup() solo invoca regulador.begin().
