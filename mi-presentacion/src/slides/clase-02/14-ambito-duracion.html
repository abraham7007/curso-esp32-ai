03 · Tipos, constantes y ámbito

Ámbito y duración de las variables

Definición

El ámbito (scope) determina desde dónde se ve un identificador; la duración (storage duration), cuánto tiempo existe su almacenamiento. Tres especificadores cubren casi todo el firmware habitual.

Especificador Qué garantiza Uso habitual
const El valor no se modifica después de inicializarse. Puede fijarse en ejecución. Parámetros de método que no deben alterar el objeto; referencias de solo lectura.
constexpr Además, el valor se conoce en tiempo de compilación y se incrusta en el código. Números de pin, periodos, umbrales — las constantes con nombre y unidad.
static Dentro de una función: conserva su valor entre llamadas. En ámbito de archivo: limita la visibilidad a esa unidad de traducción. Contadores y marcas de tiempo que deben sobrevivir a la iteración; funciones auxiliares privadas de un .cpp.

Variables globales. Cualquier módulo del programa puede escribirlas, así que un valor incorrecto no tiene un único punto de origen: hay que revisar todo el código que las alcanza. Su uso requiere una justificación explícita. En la arquitectura de este curso el estado vive dentro de cada clase, no en variables globales.

En la práctica

Un contador que debe sobrevivir entre llamadas se declara static uint32_t n = 0; dentro de la función, no como global: la inicialización ocurre una sola vez, el valor persiste, y ningún otro archivo puede tocarlo. La misma forma vale para una marca de tiempo: static uint32_t tPrevio = 0;.
