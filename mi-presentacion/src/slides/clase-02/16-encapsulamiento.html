04 · Clases y encapsulamiento

Encapsulamiento: estado privado, interfaz pública

Definición

Los datos internos de la clase se declaran private y solo se accede a ellos mediante métodos public. El resto del programa depende de la interfaz (los métodos públicos y lo que garantizan), no de la representación interna.

En la práctica

private: es el modo por defecto de class; escribirlo de forma explícita deja el límite visible. La convención adoptada marca los miembros privados con un guion bajo inicial (_pin) para distinguirlos de los parámetros del constructor en una lectura rápida.

lib/Led/Led.h 
class Led {
 private:                  // representación interna
   uint8_t _pin;           // qué terminal controla
   bool    _encendido;     // estado actual de la salida

 public:                   // interfaz que ve el resto
   explicit Led(uint8_t pin);

   void begin();           // configura el pin como salida
   void on();              // fuerza nivel alto
   void off();             // fuerza nivel bajo
   bool estaEncendido() const;   // consulta sin modificar
};
_pin y _encendido no son accesibles desde main.cpp: no existe forma de dejar el estado guardado y el nivel real del terminal en desacuerdo.

Resultado observable. Mover el LED del GPIO 2 al GPIO 4 se resuelve en la línea donde se construye el objeto, Led ledEstado(4);, sin tocar ninguna otra parte del programa. Esa independencia respecto de la asignación física de pines es el efecto concreto del encapsulamiento, no una propiedad abstracta del diseño.
