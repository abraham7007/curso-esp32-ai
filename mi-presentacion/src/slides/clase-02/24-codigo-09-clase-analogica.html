La hora del código Ejemplo 09

Clase de entrada analógica con promediado

Sobre el proyecto. Una clase EntradaAnalogica que toma una muestra por llamada y mantiene la media de las últimas dieciséis. Expone dos lectores distintos: uno para diagnosticar y otro para la aplicación.

Conceptos clave

La media móvil promedia las últimas N muestras: reduce el ruido a costa de responder algo más despacio a un cambio real. Que la clase ofrezca leerCrudo() y leerVoltios() separa el valor de diagnóstico del valor de aplicación: el primero sirve para ver qué llega, el segundo es el que se usa. Promediar es responsabilidad del módulo de adquisición, no de la lógica que consume la lectura.

Prompt para el asistente

1. Proyecto. Crea un proyecto nuevo de PlatformIO para la placa esp32dev con el framework Arduino, con la clase EntradaAnalogica en lib/EntradaAnalogica/. 2. Firmware. El constructor recibe el pin y el tamaño N de la ventana. update() toma una única muestra por llamada y actualiza la media móvil de las últimas N=16; no debe muestrear en bucle dentro de sí misma. Expone leerCrudo(), el código del conversor, y leerVoltios(), la magnitud convertida. Emite a 115200 baudios «[ADC] crudo=NNNN promedio=NNNN v=N.NNN». 3. Simulación. Añade la simulación de Wokwi con el potenciómetro: extremos a 3V3 y GND, cursor al GPIO 32. 4. Diagramas. Entrega dos en Excalidraw. El diagrama de flujo de update(), con la ventana de N muestras y la actualización de la media. Y una gráfica de crudo y promedio superpuestos ante un salto del cursor, con el retraso señalado.

Análisis

Con el cursor quieto, comparar las dos columnas: el crudo oscila ±14 códigos y el promedio ±1. Esa es la medida del filtro. Después mover el cursor de golpe y observar cuántas líneas tarda el promedio en alcanzar al crudo: ese retraso es el precio, y con N = 16 son dieciséis muestras.
