Función de cada directorio en la compilación

Definición

Cada directorio del proyecto tiene una función fija en el sistema de construcción. La decisión de dónde colocar un archivo no es una preferencia de orden: determina cómo se compila, con qué sintaxis se incluye y si el módulo puede reutilizarse en otro proyecto.

proyecto/
├── especificación
├── lo que no se versiona
├── alcance global
├── módulos reutilizables
│ └── Led/Led.h + Led.cpp
├── código de este proyecto
│ └── main.cppcoordina los módulos
└── lógica verificable

En la práctica

Todo lo que está en lib/<Nombre>/ se compila como biblioteca propia y se incluye con #include <Nombre.h>. Lo que está en src/ se compila siempre y se incluye con #include "archivo.h".
