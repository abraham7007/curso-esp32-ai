03 · Tipos, constantes y ámbito

Constantes con nombre y unidad

Definición

Un literal suelto no documenta qué magnitud representa ni en qué unidad está expresada, y obliga a buscar cada aparición cuando el valor cambia. Una constante con nombre fija la magnitud en un único punto del programa y la identifica en cada uso.

main.cpp · literales sueltos Así no 
void loop() {
  delay(2000);
  analogWrite(2, 191);

  int v = analogRead(34);
  if (v > 3000) {
    Serial.println("umbral");
  }
}
2000 podrían ser milisegundos o microsegundos; 191 no dice que sea el 75 % de 255; 3000 no indica que es un código del conversor y no una tensión en milivoltios.
main.cpp · constantes con nombre Así sí 
constexpr uint32_t PERIODO_PARPADEO_MS = 2000;
constexpr uint8_t  DUTY_75_PCT = 191;
constexpr uint16_t UMBRAL_ADC = 3000;

void loop() {
  delay(PERIODO_PARPADEO_MS);
  analogWrite(PIN_LED, DUTY_75_PCT);

  uint16_t v = analogRead(PIN_SENSOR);
  if (v > UMBRAL_ADC) { Serial.println("umbral"); }
}
El nombre indica la magnitud y el sufijo su unidad. Cambiar el periodo de parpadeo es editar una línea.
En la práctica

constexpr se evalúa en tiempo de compilación: el valor queda incrustado en la instrucción y no ocupa RAM, a diferencia de una variable global const, que sí puede reservarla. El sufijo del nombre lleva la unidad (_MS, _PCT, _HZ, _ADC) para que la magnitud sea legible en el punto de uso, sin volver a la declaración.
