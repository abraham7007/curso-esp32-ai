01 · Modelado del comportamiento

Acumulación de variables de control

Situación de partida

Un programa que crece añadiendo una variable booleana por cada condición termina con un conjunto de banderas independientes: enMarcha, esperandoPeaton, yaAviso, bloqueado.

Con n banderas hay 2n combinaciones posibles, y el programa solo define el comportamiento de unas pocas. El resto son estados alcanzables que nadie ha especificado.

Síntoma reconocible

Corregir un fallo obliga a añadir otra bandera, y esa corrección habilita una combinación nueva que vuelve a fallar. La causa no es falta de cuidado: el modelo permite representar situaciones que el dispositivo no puede tener.

Con diez banderas hay 1024 situaciones alcanzables y el programa define cinco. Con diez estados declarados hay exactamente diez.

enMarcha=1 esperandoPeaton=1 yaAviso=0 bloqueado=1 > ninguna rama del if contempla esta combinacion
Solución estructural

Se sustituye el conjunto de banderas por una sola variable de estado con un número cerrado de valores. El espacio de situaciones deja de crecer de forma exponencial y pasa a ser enumerable, que es la condición para poder verificarlo.
