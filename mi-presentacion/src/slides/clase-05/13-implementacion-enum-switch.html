Implementación con tipo enumerado y selección múltiple

Forma de referencia

El estado se declara como enum class y el bucle resuelve la transición en un switch con un case por estado. Es la forma de referencia hasta unos diez estados; por encima de esa escala conviene la tabla en memoria de la lámina siguiente.

Por qué enum class y no #define

Con enum class el compilador rechaza asignar un entero a la variable de estado y, con -Wswitch activo, advierte de todo case que falte. Una constante numérica no ofrece ninguna de las dos comprobaciones, y ambas son gratuitas.

estructura mínima completa 
enum class Estado : uint8_t { VERDE, AMBAR, ROJO };
Estado estado = Estado::VERDE;   // estado inicial declarado

void loop() {
  Evento e = leerEvento();       // entradas → evento
  Estado anterior = estado;

  switch (estado) {              // una rama por estado
    case Estado::VERDE:
      if (e == Evento::PULSADOR && millis() - tEntrada >= 8000)
        estado = Estado::AMBAR;
      break;
    case Estado::AMBAR: /* … */ break;
    case Estado::ROJO:  /* … */ break;
  }

  if (estado != anterior) {     // acciones de entrada, una vez
    tEntrada = millis(); aplicarSalidas(estado);
  }
}
