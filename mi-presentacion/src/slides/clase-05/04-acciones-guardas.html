01 · Modelado del comportamiento

Acciones de entrada, de salida y condiciones de guarda

Definición

La acción de entrada se ejecuta una sola vez al llegar al estado; la acción de salida, una sola vez al abandonarlo. Ninguna de las dos se repite mientras el estado permanece activo.

La condición de guarda (condición de guarda) (condición de guarda) es una expresión booleana que acompaña a una transición: el evento la dispara solo si la condición se cumple. Un mismo evento puede llevar a estados distintos según la guarda que se satisfaga.

Ejemplo

En un cargador, el evento VENCE_MEDIDA lleva a TENSION_CONSTANTE si la guarda v >= 4,20 V se cumple, y mantiene el estado actual si no. Mismo evento, dos destinos.

acción de entrada · una vez 
// La transición cambia el estado y ejecuta la acción de entrada.
// Al estar dentro del if, se ejecuta una sola vez.
if (evento == VENCE_TEMPORIZADOR) {
  estado = Estado::AMBAR;
  digitalWrite(PIN_AMBAR, HIGH);   // acción de entrada
  tInicio = millis();              // acción de entrada
}
Así no acción repetida en cada iteración 
case Estado::AMBAR:
  tInicio = millis();   // se reinicia en cada vuelta del bucle
  if (millis() - tInicio > 3000) estado = Estado::ROJO;
  break;   // la condición nunca se cumple: el estado no avanza
Regla de implementación

Lo que debe ocurrir una vez va en la transición; lo que debe evaluarse en cada iteración va en el cuerpo del estado. Confundir ambos produce el fallo del panel derecho: un timestamp que se reinicia sola y un estado que no progresa nunca.
