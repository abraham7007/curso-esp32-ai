Inyección de eventos por el puerto serie

Procedimiento

Si la función que produce los eventos admite además una fuente por el puerto serie, la máquina puede recorrerse entera sin tocar el hardware. Un carácter por evento basta.

Qué permite comprobar

Recorrer las seis filas de la tabla de transiciones toma segundos, y puede repetirse tras cada cambio. Situaciones que exigirían averiar un sensor, un fin de carrera que no llega, se provocan sin más que no enviar el carácter correspondiente.

Relación con la prueba automatizada

Una secuencia de caracteres y la traza que debe producir constituyen un caso de prueba reproducible. Es el primer paso hacia la prueba automatizada del firmware, y no exige más herramientas que el monitor serie.

Así sí dos fuentes, un solo evento 
Evento leerEvento() {
  if (Serial.available()) {        // fuente de ensayo
    switch (Serial.read()) {
      case 'p': return Evento::PULSADOR;
      case 'a': return Evento::FIN_CARRERA_ABRE;
    }
  }
  return leerEntradasFisicas();  // fuente real
}
