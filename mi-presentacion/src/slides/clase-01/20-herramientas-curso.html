05 · Pila de software y herramientas

Cadena de herramientas

Las cuatro herramientas cubren funciones distintas y complementarias: ninguna sustituye a las otras tres.

Herramienta Qué automatiza Qué no hace
Arduino IDE Editor, compilador y herramienta de flasheo integrados. Gestión de librerías por interfaz gráfica. No declara versiones exactas de las dependencias ni separa el proyecto en módulos.
VS Code + PlatformIO Lo anterior, más especificación reproducible en platformio.ini, múltiples entornos de compilación, gestor de dependencias con versión acotada e integración con control de versiones. No simula el circuito.
Wokwi Simulación del circuito y ejecución del firmware sin hardware físico. Analizador lógico y monitor serie integrados. No reproduce tiempos reales de periféricos externos, ruido eléctrico, consumo real ni defectos de conexión.
Agente de código Claude Code, opencode, Antigravity CLI Crea el proyecto, escribe el firmware y monta la simulación a partir de un prompt. Lee los errores del compilador y la traza del monitor, y corrige sobre el mismo repositorio. No decide qué construir ni garantiza que lo escrito sea correcto: llega a invocar librerías que no existen, como mide el artículo de esta sesión.
Uso combinado

El firmware se escribe y se compila en VS Code con PlatformIO. La verificación inicial de cada ejemplo se realiza en Wokwi; la puesta en marcha final, sobre la placa física. El Arduino IDE queda fuera de este flujo de trabajo: se referencia porque constituye la puerta de entrada más frecuente antes de un entorno de trabajo profesional.

El agente de código entra en los 51 ejemplos de La hora del código: cada uno trae el prompt ya escrito, y lo que el agente entrega se contrasta contra la traza esperada antes de darlo por bueno. El agente redacta; quien decide si el resultado sirve es el estudiante, y para eso está la sección de análisis.
