PlatformIO encadena cinco programas, y cada uno produce errores de forma distinta. Antes de pulsar el enlazador, plantear la pregunta. Pregunta de predicción: si el compilador ya revisó el código, ¿por qué puede fallar una etapa posterior? El compilador procesa cada archivo por separado, y el enlazador es la etapa que comprueba que todo lo declarado esté definido. La primera línea del error identifica la etapa y acota dónde buscar.

Para estudiar

En la práctica

Las cuatro primeras etapas son la toolchain cruzada xtensa-esp32-elf- (GCC); la quinta, esptool.py elf2image. pio run -v muestra cada orden que se ejecuta.

Dónde aparece

  • .pio/build/esp32dev/ guarda los .o, el .elf y el .bin.
  • El .elf conserva símbolos de depuración y no se graba; el .bin es mucho menor.
  • «The program size … is greater than maximum allowed» lo emite la comprobación de tamaño que PlatformIO hace tras enlazar, no esptool.

Errores frecuentes

Corregir una línea que no contiene el error. Un undefined reference indica que falta un archivo o una librería.
