Estructura de directorios que impone PlatformIO

PlatformIO impone una estructura de directorios fija. Cada uno tiene una función definida en el sistema de construcción; respetarla es condición para que el proyecto se compile de forma idéntica en otro equipo.

raíz — el proyecto completo
├── placa, framework y librerías
├── descripción del circuito para el simulador
├── código específico del proyecto
│ └── el programa
├── módulos propios
├── cabeceras compartidas
├── pruebas unitarias
└── generado, no se versiona
