05 · Temporizadores y base de tiempo

Instante de la medida y timestamp

Definición

El timestamp (timestamp) es el instante en que se tomó la medida, transportado junto a ella. Sin esa referencia no se puede saber si un dato es reciente, ni calcular una velocidad de cambio, ni ordenar medidas procedentes de varias fuentes.

Un dato sin timestamp no permite distinguir un sensor que dejó de responder de uno que mide una magnitud constante: en los dos casos la aplicación recibe el mismo número una vez tras otra.

En la práctica

Al principio basta con millis(), el tiempo transcurrido desde el arranque: no es una fecha, pero permite calcular intervalos, ordenar medidas y detectar datos obsoletos. La fecha real llega en la Sesión 10 con la sincronización por red.

lib/Sensor/Medida.h · el dato que la aplicación recibe Comparación 
float temperatura;   // 23,4 — ¿de qué instante? ¿es válido?

struct Medida {
  float    valor;    // magnitud ya convertida a unidades de ingeniería
  uint32_t ms;       // millis() del instante de lectura
  uint8_t  estado;   // OK | FUERA_DE_RANGO | SIN_RESPUESTA
};

// en el bucle: el dato caduca aunque el sensor siga respondiendo
Medida m = sensor.read();
if (millis() - m.ms > INTERVALO_MAXIMO_MS) {
  m.estado = OBSOLETO;
}
La estructura viaja completa: valor, instante y estado. La aplicación decide con las tres cosas, no con un número suelto.
