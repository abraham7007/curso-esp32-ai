02 · Red e Internet

Dirección IP, DNS y puerto

Al conectarse, el ESP32 recibe del router una IP privada (DHCP). El DNS devuelve la IP pública de un servidor a partir de su nombre.

Pregunta de predicción: el ESP32 conoce el nombre api.coingecko.com y los paquetes se dirigen a direcciones numéricas; ¿qué servicio entrega la IP del servidor? La entrega el DNS. Recorrer las tres franjas: la IP propia llega por DHCP al conectarse; la del servidor, por DNS antes de cada conexión; el puerto sale de la URL (https → 443).

La IP del ESP32 es privada, válida dentro de la red local; la lámina 07 muestra qué ocurre con ella al salir a Internet. La IP del servidor cambia: CoinGecko está detrás de Cloudflare y el DNS devuelve varias.

Para estudiar

En la práctica

WiFi.localIP(), WiFi.gatewayIP() y WiFi.dnsIP() muestran lo que entregó el DHCP. WiFi.hostByName("api.coingecko.com", ip) devuelve 1 si el DNS respondió. HTTPClient hace la consulta DNS por su cuenta dentro de http.GET().

Las cifras

10.13.37.2 es la IP en Wokwi desde VS Code (pasarela privada incluida); en wokwi.com, 10.10.0.2. En una red doméstica suele ser 192.168.x.x. 104.20.41.132 es una de las respuestas del DNS el 13/10/2026; cambia.

Errores frecuentes

Fijar la IP del servidor en el código; cuando cambia, la petición falla sin un mensaje que lo explique.
