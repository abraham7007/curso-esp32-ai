01 · Sensores y diseño del driver

Interfaz común de la capa de adquisición

Definición

Todos los sensores del proyecto se exponen a la aplicación con los mismos cuatro métodos, de significado fijo:

  • begin() — configura el sensor y devuelve si la configuración tuvo éxito.
  • read() — entrega la última medida en unidades físicas.
  • isReady() — indica si hay un dato nuevo disponible.
  • status() — informa del estado del sensor: correcto, sin respuesta o fuera de rango.
En la práctica

La aplicación declara Sensor* fuente = &sensorAnalogico; y llama siempre fuente->read(). Sustituir el sensor es cambiar esa única línea. El mecanismo se llama polimorfismo (polymorphism): la llamada se resuelve en tiempo de ejecución según el objeto real al que apunta.

Sensor.h 
enum class Estado { OK, SIN_RESPUESTA, FUERA_DE_RANGO };

class Sensor {                    // clase base abstracta
public:
  virtual bool   begin()   = 0;   // método virtual puro
  virtual float  read()    = 0;
  virtual bool   isReady() = 0;
  virtual Estado status()  = 0;
  virtual ~Sensor() = default;
};

class SensorAnalogico : public Sensor { /* ADC  */ };
class SensorI2C       : public Sensor { /* Wire */ };
