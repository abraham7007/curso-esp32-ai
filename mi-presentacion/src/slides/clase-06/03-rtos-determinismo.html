Sistema operativo de tiempo real y determinismo

Sistema operativo de tiempo real

Sistema operativo cuyo planificador garantiza un plazo máximo entre que una tarea queda preparada y recibe el procesador. La garantía es sobre el peor caso, no sobre el promedio.

Se abrevia RTOS, del inglés real-time operating system.

Determinismo

Propiedad de un sistema cuyo tiempo de respuesta está acotado y es conocido. Un sistema determinista no es necesariamente rápido: es uno cuyo retraso máximo puede calcularse antes de ejecutarlo.

Un sistema que responde en 2 ms el 99 % de las veces y en 400 ms el 1 % restante no es determinista.

Tiempo real estricto

Incumplir el plazo constituye un fallo del sistema, con consecuencias sobre la seguridad o sobre el producto.

Disparo de un airbag, control de un motor de tracción, corte de una prensa ante la detección de un obstáculo.

Tiempo real flexible

Incumplir el plazo degrada la calidad del resultado sin invalidarlo. Se tolera una proporción acotada de incumplimientos.

Refresco de una pantalla, registro de temperatura cada minuto, transmisión de telemetría a una plataforma.

Dónde se sitúa este curso

FreeRTOS sobre ESP32 con el núcleo de Arduino cubre tiempo real flexible. La pila de comunicaciones inalámbricas introduce interrupciones cuya frecuencia no controla el programa, de modo que el peor caso no puede acotarse con rigor. Los proyectos con requisito estricto separan esa función en un microcontrolador dedicado.
