Yetiştiren, B.; Özsoy, I.; Ayerdem, M.; Tüzün, E. (2023). Evaluating the Code Quality of AI-Assisted Code Generation Tools: An Empirical Study. arXiv. arXiv:2304.10778

Proporción de código válido y correcto entre las herramientas de generación

Objetivo
  • Medir la calidad del código generado más allá de si funciona.
  • Cinco dimensiones: validez, corrección, seguridad, fiabilidad y mantenibilidad.
  • 164 problemas planteados a tres herramientas de generación asistida.
Resultados
  • Generaciones válidas: 150, 148 y 153 de 164 — entre el 90,2 % y el 93,3 %.
  • La diferencia entre las tres herramientas es pequeña.
  • Las generaciones no válidas puntúan cero en corrección: no se descartan.
  • Solo dos de las cinco dimensiones se comprueban ejecutando.
Conclusiones
  • Las tres producen código válido en proporción alta y semejante.
  • La diferencia relevante no está en si el código se ejecuta, sino en las otras cuatro dimensiones.
  • Un fragmento válido y correcto puede seguir siendo inseguro o inmantenible.
