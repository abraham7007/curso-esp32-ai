01 · Tareas y planificador

La tarea y su pila de ejecución

Definición

Una tarea es una función con bucle propio y, sobre todo, con pila propia. Esa pila guarda sus variables locales y la dirección de retorno de cada llamada, y es lo que permite interrumpirla en cualquier punto y reanudarla exactamente ahí.

En el código

xTaskCreatePinnedToCore(funcion, "nombre", pila, param, prioridad, &handle, nucleo). El tamaño de pila se expresa en palabras, no en bytes: en el ESP32 una palabra son 4 bytes, de modo que 4096 reserva 16 kB.

La función de una tarea no debe retornar nunca. Si termina, hay que eliminarla con vTaskDelete(NULL); salir por el final de la función provoca el reinicio del sistema.

creación y estructura 
void tareaMuestreo(void *param) {
  for (;;) {                    // no retorna nunca
    int v = analogRead(34);
    vTaskDelay(pdMS_TO_TICKS(1));  // cede el procesador
  }
}

void setup() {
  xTaskCreatePinnedToCore(
    tareaMuestreo, "muestreo",
    4096,        // pila en palabras → 16 kB
    nullptr,
    3,           // prioridad; loop() usa 1
    nullptr,
    1);          // núcleo 1
}

Cada tarea reserva su pila en SRAM al crearse. Diez tareas de 4096 palabras ocupan 160 kB de los 320 kB disponibles, y esa memoria se reserva aunque la tarea esté bloqueada.
