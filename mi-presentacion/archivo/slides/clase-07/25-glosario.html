02 · Protocolo HTTP y APIs REST

Glosario de la sesión

Socket

Extremo de una conexión: el par dirección IP más puerto. Una conexión queda determinada por sus dos sockets.

NAT network address translation

Sustitución de la dirección privada de origen por la pública del router. Solo un paquete de salida crea la entrada de la tabla.

DHCP y DNS DHCP / DNS

El primero reparte dirección, máscara y puerta de enlace al entrar en la red; el segundo traduce nombres a direcciones y su fallo delata una red sin salida a internet.

RSSI received signal strength indicator

Potencia de la señal recibida, en dBm. Por debajo de −80 dBm el enlace se pierde y se recupera de forma repetida.

MAC media access control address

Dirección de seis bytes grabada en fabricación. No cambia al mudar de red.

TCP y UDP TCP / UDP

Protocolos de transporte. TCP garantiza entrega y orden con 20 bytes de cabecera; UDP no garantiza nada y ocupa 8.

HTTPS HTTP over TLS

HTTP cifrado con TLS. Exige hora válida, memoria adicional y un certificado raíz con el que verificar la cadena de confianza.

API REST REST API

Interfaz que expone recursos por su ruta, operados con los métodos de HTTP. El servidor no guarda estado entre peticiones.

Idempotencia idempotence

Propiedad de una operación que da el mismo resultado al repetirse. Decide si un reintento es seguro.

Token bearer token

Credencial que acompaña a cada petición en la cabecera Authorization. Nunca se versiona.

Backoff exponencial exponential backoff

Reintento que duplica la espera tras cada fallo, hasta un máximo. Reduce consumo y evita saturar al servidor.
