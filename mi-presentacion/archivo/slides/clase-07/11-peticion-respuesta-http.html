02 · Protocolo HTTP y APIs REST

Estructura de una petición y de una respuesta HTTP

Cuatro partes en cada dirección

La petición lleva método, ruta, cabeceras y cuerpo. La respuesta sustituye las dos primeras por un código de estado y conserva las otras dos. Una línea en blanco separa las cabeceras del cuerpo.

En el código

La biblioteca HTTPClient compone esas partes: http.begin(url), http.addHeader("Content-Type", "application/json"), int codigo = http.POST(cuerpo) y http.getString(). Un código negativo señala un fallo de la propia biblioteca, no del servidor.

http.getString() reserva en memoria la respuesta completa. Con una respuesta de 200 kB agota la memoria libre y el dispositivo se reinicia. La alternativa es leer del flujo por partes, que es el contenido de una lámina posterior.

lo que viaja por el socket
